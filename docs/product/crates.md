# Crates

**What it is:** named, unordered collections of albums — "jazz," "road trip music," "gifts for friends." A crate is a place to group albums by personal criteria; membership is the point, not position.

## Why

The library gives you ownership over your collection, but no way to organise it beyond format filters and sort. Tags are lightweight inline labels — not browsable objects. Crates fill the gap: a named collection with its own page that you can build, browse, and share context around.

## What a user can do

| Action | Result |
|---|---|
| Create a crate | New named crate appears in the Crates tab |
| Open a crate | Detail page showing all member albums |
| Edit a crate | Modal to add albums (search library) and remove albums |
| Delete a crate | Crate and all memberships removed; albums unaffected |

## Headline rules

- Crates are unordered — no ranking or sorting of members within a crate.
- An album can belong to multiple crates.
- Crates are distinct from tags: tags are inline labels on an album; crates are browsable collections with their own pages.
- Crates live in a dedicated bottom nav tab alongside Library and Radar.

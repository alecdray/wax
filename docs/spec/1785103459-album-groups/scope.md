# Album Groups

Named, unordered collections that a user creates to organise albums by any personal criteria — "jazz," "road trip music," "gifts for friends." Groups are first-class objects with their own pages and membership management; they are distinct from tags (lightweight inline labels) and ranked lists (where position is the point). The deliverable for this chunk of work is a fully functional groups feature: create/rename/delete groups, add/remove albums, and a group detail page — surfaced through the library and album detail flows.
